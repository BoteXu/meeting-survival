# 分层选科与专业扩展 · v0.11.0

首页只展示14个学科门类，选中后才展开该门类的专业路线。可以返回路径中的门类重新选专业，也可以回到大类。新开局需要先选专业；已有存档可以直接继续，不必重新选。

本版在哲学、经济学、法学、教育学、文学、历史学、理学、工学、农学、军事学、管理学、艺术学各增加5条路线，共新增60条路线与720个研究方向。总量为155条路线、1716个方向、638种结局、593位虚构导师。交叉学科可从扩展后的专业中组合两侧，仍需分别完成两侧准备。

有两条选题路径：

1. 大类 → 专业路线 → 可选细分领域 → 具体研究方向 → 导师。
2. 大类 → 专业路线 → 导师主页 → 导师提供的1–3个子方向。

18条路线提供54个可选细分领域，包括心血管、影像、神经、儿科、口腔、民商法、刑事法、语言学、中国语言文学、中国史、软件、电气、生命系统、金融、课程教学、作物、信息资源与音乐。可以跳过细分领域浏览本专业全部方向，也可以直接先看导师。未选具体方向时，导师确认按钮保持不可用，选择一个方向后才开始入组。

例如：工学 → 软件工程 → 测试与质量 → 软件测试；文学 → 语言学与应用语言 → 使用与社会情境 → 语用学；医学 → 临床医学 → 内科学 → 心血管医学 → 疾病与临床问题 → 心力衰竭。目录把正式学科、专科领域与研究主题放在可浏览的层级中，不声称每个节点都对应官方二级或三级学科资格。

选择最终方向后，当前课题、准备按钮、原始材料版本和组会追问使用同一个方向ID。切换大类清除旧专业与细分领域；换方向或课题版本后，旧材料只保留为线索。新路线也接入10类资源排期、长期研究剧情、临时交办、投稿、人物生涯与阶段目标。

新增导师使用实际方向ID，有1–3个子方向，涵盖青年、中坚、资深层级；资源、指导习惯、个人截止和晋升仍影响生涯。人物、学校与代表成果均为虚构。

新增专业各有研究问题、方向名称、审核焦点、提问与失败/滑稽结局；相近专业共享门类突发模板及资源剧情框架。这不是155套完全独立长篇剧本。内容审核属于Codex编辑与机制检查，没有外部学科专家逐条签审。

[逐专业审核记录](PROFESSIONAL_REVIEW.md)和[1716项研究方向审计表](DIRECTION_REVIEW.csv)列出实际范围、问题示例、连接标签和同名主题说明。

验证包括450周/5850次生活行动、1647个单路线方向的实际准备与新版本失效、18路线细分分组完整性、导师方向到实际课题的一致性、完整存档往返、默认折叠、导师延后选题及390px窄屏浏览。测试模拟不等于真机安装或外部专家审核。


医学先进入12个一级学科／专业类别入口，再选择58个二级或专业领域入口，最后展开51条可玩路线。一级名称依据[教育部2022目录](https://www.moe.gov.cn/srcsite/A22/moe_833/202209/t20220914_660828.html)，医学技术单列为1058专业学位类别。二级以下包含正式名称、院校自主专业领域、临床专科和研究主题，页面有对应标记，不称为全国统一三级目录。

每条普通专业路线有3–4位直接覆盖该专业的虚构导师，每人1–3个实际方向，加上24位原有导师，共593位。搜索与分页避免一次列出所有人。选过专业领域后，招生页筛掉不相符的子方向；未选导师或未定方向不能入组。
