# 专业内容与连续问答（v0.14.8）

本版针对所有学科方向处理内容错配、套话叠加和重复追问。药学是专项细化之一，整体修改覆盖14个门类、219条学科路线和2,500个方向。

## 具体内容

新增62组按所属学科限定的讨论案例，包含材料、核对思路、可能漏洞、解释范围、基础问题与探索问题，接入1,047个方向。它们是共享案例，不能理解为1,047份独立专家审核。其中包括：

- 数学：结构与映射、收敛与交换极限、数值误差、相空间与稳定性。
- 计算机和工科：事务隔离、分布式故障、程序行为约定、模型选择、闭环控制、测量链路、结构边界和完整系统能耗。
- 哲学、经济和法学：模态前提、证成、规范理由、就业退出、税负归宿、赔付窗口、事实要素、证明力和权利对象。
- 教育、语言与文学：撤去辅助后的学习、融合支持、构念测量、音位对立、句法接受度、翻译目的和叙述声音。
- 历史与艺术：原件与编纂时间、层位与定年、修复与原物、剪辑叙事、演绎与声场、作者意图与接受。
- 农学、医学、管理与交叉：种质与环境、土层与管理、个体与养殖场、发育阶段、功能与参与、合并范围、全链等待、技术指标与健康结局的接口。
- 军事门类限于公开历史、组织与制度解释，不提供现实操作方案。

电影方向此前因路线名称含“影像”误接医学影像模块，现由所属门类控制；数学动力系统、农业经济与工程、机电控制的含义也优先按所属领域判断。

药学专项增加16个稳定方向ID，药理学入口现含17个分支，与临床药理学分开。37个药学／临床药理方向分别编写案例；心血管、肾脏、神经、内分泌、肿瘤等有各自的材料、基础与探索问题。新方向至少有6位不同层级的虚构导师，原有导师ID和姓名保持兼容。

## 减少重复

日常准备和普通专业问答只展示当前材料与问题，不再叠加数段相同的“提案、核对、范围”说明。问题标题显示完整问题，正文提供材料和现场线索，不把同一句再问一遍。

五类问答分别关注文献、方法、原始记录、结论边界与解释表达；每类轮换四种讨论角度。2,500个方向因此有50,000个可生成的基础问答位置，这个数字是组合位置数，**不是50,000道独立手写或专家认证的知识题**。很多方向仍共享学科材料。细化案例替换材料与问题，不能仅靠更换方向名称证明专业充分。

场次种子影响起始角度，实际回答后记录方向、问题类别、角度和研究侧重；读档保留下一次角度，下一场组会轮换起始角度。普通题型随汇报阶段区分，不再把没有标注的专业问题全当成结论边界题。当前阶段题目用尽时，优先选用其他符合条件且本场尚未出现的问题，保留最低问答数量、明确失败行为和关键追问。长期重复某个研究主题仍可能出现，四个角度也不是无限题库。

导师指出漏洞和接续追问保留原来的处理状态；转向后的旧课题故事仍指向原方向。故意拒绝核对、虚报完成、借用未落实等后果不会因为文字调整而消失。

## 准备与学习

阅读内容库不生成准备。只有实际选择工作，才留下对应方向、课题版本和研究侧重的记录；新版本不能复用旧版本的准备作为完成证据。回应与解析会使用本方向实际材料，解析保存到学习札记。

背景入口按学科／方法范围提供，不能作为游戏虚构发现的论文证据。药理分类与概念背景参考[ASPET药理学知识目标（2022）](https://www.aspet.org/docs/default-source/education-files/pharmacology-knowledge-objectives-2022-final.pdf)，这是领域背景，不宣称采用某国正式学位目录的全部层级。其余背景链接和查阅范围见方向内容库；对教材和方法的外部链接不等于复制教材，也不等于专业签审。

## 审核记录与范围

[逐方向对应记录](SUBJECT_DIALOGUE_AUDIT.csv)检查方向、材料、问题及档案的对应关系，并分别标出独立药学案例、按学科限定的共享案例和仍使用共享模块的方向。全量自动检查包括实际准备后的问答、课题版本失效和读取不改变状态。

现阶段完成的是内容编辑、专业归属与机制验证。尚未取得2,500个方向的逐题外部专家签审，也没有声称补齐每个方向的全部前沿论文。医学文本用于游戏内研究讨论，不含患者用药方案或实验执行步骤。

中英文对应新增文本；日文和韩文界面保留，尚无人工译文的新增长文本按现有规则回退英文。
