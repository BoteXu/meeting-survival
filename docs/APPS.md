# 免费应用版与完整存档

正式地址：https://botexu.github.io/meeting-survival/

Android：Chrome打开正式地址，菜单→安装应用或添加到主屏幕。
iPhone / iPad：Safari打开正式地址，分享→添加到主屏幕，启用作为网页App打开。
电脑：Edge / Chrome安装按钮，或下载Release中的Windows应用包，完整解压后打开“组会求生.exe”。无需管理员权限。Windows窗口使用本机已有浏览器，程序与HTML须同目录；升级或移动下载包后继续使用固定本机应用目录。
macOS / Linux也可以用浏览器安装，或者下载离线HTML打开。

手机应用为可安装离线网页应用PWA，没有独立APK / IPA；首次打开保持网络直到“存档与安装”显示离线资源已准备好，然后可断网游玩。应用更新随正式网页版本发布，关闭旧应用重新打开后启用新资源。Windows下载版升级需下载新包。

所有游戏状态只存在本机。自动保存包括进行中的一周、组会、生涯、人物、年鉴与结局。IndexedDB保留最近快照，localStorage保存即时状态。打开“存档与安装”可导出完整JSON，导入会先检查结构和游戏状态，再显示待恢复概要，确认恢复时发起现有存档备份。恢复快照也会先备份。

v0.12.0起，换新专业或新导师开启生涯前，会将当前局保存到“暂停的生涯”，最多8段。点击继续时，当前局与所选暂停局交换位置，累计结局与生涯统计保留。每段可单独下载，移除需要再点击一次确认，同时发起该段存档下载；请保留文件备份。完整JSON也包含整个暂停列表。

浏览器、安装的网页应用、Windows应用的本机存储可能互相独立；转移设备或浏览器应导出JSON再导入。卸载、手动清理网站数据、设备故障都可能删除本机存档。浏览器持久存储保护不是永久保证，定期保留JSON文件。

Windows数据位于当前用户的LocalAppData/MeetingSurvival；程序只使用本机离线HTML和既有Edge/Chrome，不需要账户、云同步或付费服务。

费用：0 RMB。没有广告、内购、自动上传存档或模型API调用。


世界设定与校园故事集可从游戏页脚“世界观与校园手册”打开。Windows包附带世界设定集.html，启动器会复制到固定运行目录；也可以单独下载阅读器离线看。PWA完整缓存包括阅读器。大型阅读内容按目录打开，不在游戏首页展开。
