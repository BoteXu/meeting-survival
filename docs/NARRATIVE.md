# v0.14.1 人物与故事编辑说明

本次区分公开简历与相处以后听到的背景：招生页保留学历、任职、代表工作和指导安排，完整转折、学生记忆与私人片段由实际后续事件逐步展示。查看本身不消耗随机数或记录完成；回应后存入生涯，旧存档没有此字段也能继续。设定集供查阅完整背景，不把小说结果写进玩家存档。

年轻导师只使用符合初期带组的背景；旧书与历届书签说明来自此前团队，首批独立指导学生仍在读。加入现校前的代表工作明确旧团队指导关系，每篇期刊与论文类型按其实际方向决定。小说高年级学生的来源、投稿状态及年末去向进一步对齐；共享场景通过有约束的衔接组合，六类结局保持开放。修订范围和实际检查见[QA_v0.14.1](QA_v0.14.1.md)。

这轮保持学科、导师、方向和结局数量，重点补写现有内容的来历、人物动机、阶段进展与后续。姓名相似并不指代现实人物；背景名称独立虚构，不提供现实机构的一对一替名表。

## 导师主页

4974位导师均有本科、博士、国内或海外合作、加入现校与独立招生或职级晋升时间线，按年代排列。访问、博士后合作与博士学位分别表述，不把短期访问写成海外学位。小传补充曾遇到的退稿、版本、合作或表达问题，并解释这些经历如何形成现在的指导习惯。

成果介绍包括1–3个实际子方向的代表工作、年份、虚构刊物、游戏内档位、作者身份及修订经历。文本、设计与其他研究路线采用不同的成果题材，作品展示、会议摘要、全文接收分别记录。当前课题、课程、招生态度、可提供的资源和私人生活补充阅读线索，不保证游戏里每次求助成功。

人物由稳定ID、方向、职级、指导风格、学校、年份及生活素材组合生成。33组专业研究素材提供具体研究对象、问题和代表论文题材；八类经历包括反复退修、合作拆稿、学生改题、申请失利、报告受质疑、接手旧课题、课程纠错和资源中断。12种指导习惯与八组生活片段补充日常细节。每份小传有自己的身份与履历锚点，但多个导师仍共享素材；这不是数千篇完全独立手写的人物小说。新增研究室成立后的资源与交接经历、同领域真实虚构人物之间的来往、学生成长记忆和私人生活留下的痕迹；每位导师有四阶段叙述线，明确属于背景及可能分岔。已有导师的ID、姓名、方向、风格、职级与预算参数保留。

## 虚构学术环境

10个城市、10所学校、10类学科资源环境、分学科实验室名称、10类年会和78个虚构期刊共同构成背景。城市的交通、共享平台、档案预约、合作季度安排、时差和出行限制提供现实感。导师跨方向指导时，任职学校保持一致。

期刊1区、2区、3—4区只是游戏内三个难度档位；不对应真实JCR、中科院分区、刊物影响因子或院校考核标准。原来的brief、methods、frontier三个投稿ID与审稿概率、等待机制保留。按稿件学科解析刊物名称，旧稿和旧存档继续可用。导师简介中的历史成果是人物背景，不计入玩家的接收成果。

## 故事编辑范围

- 10种资源／学科长线：重写30段场景，通过邮件、文件、人物对话和截止日期推进入口受阻、条件差异及交付；覆盖219条路线，接入具体方向、导师任职地点、版本与前段行动。
- 8条校园支线：重写24段场景，补写材料的主人、交流许可、时间限制、转述动机和实际核对；三次核对仍由原有规则决定。
- 4条校园生活线：重写15段场景，食堂、桌游、校猫和乐队有自己的约定、缺席与交接，不要求每次生活安排转化成学术成果。
- 多周伏笔：邮件、借用、招生引用、食堂合作与失败课堂案例，明确线索、同意、承诺和真正行动的差别。
- 人物目标、临时交办、合作署名、阶段检查、补救和投稿：补充各方自己的截止与责任，不把同门只写成救场工具。
- 766种既有结局：原结果和触发条件保留，按毕业、延期、投稿、合作、借用、田野、档案和校园经历等内容选择简短后续，移除统一的说理尾段。结局后续是一种叙述可能，不替玩家自动完成新工作。

共同世界与刊物对照见[核心设定](WORLD.md)。[29册百科与校园小说](worldbook/README.md)提供2,188,145正文汉字，百科1,179,779、小说1,008,366，比例53.9% / 46.1%。精选405位人物对应405篇四幕学年短篇，全部4974位导师的扩充主页仍保留。小说与游戏共享人物及学科，但独立事件不会成为玩家已经发生的成果。

大型设定集使用人工编写的场景框架和人物设定组合，包含复用段落。24种四幕主场景、10类资源情境、6段生活插曲、4段后续与方向问题共同编排。没有声称405条都是完全独立原创情节，阅读器提供方法、计数与目录。去重段落正文1,775,957汉字仍包括改名与方向化用的相近段落，不能解释为独立手写字数。地理、学校来历、资金机构与刊期属于叙述设定，未被写成额外已实现的政策机制。

不同方向仍会共享资源与剧情框架。本轮没有声称每个方向已有一篇独立长篇，也没有逐专业外部专家签审。

## 展示与语言

导师主页用年份时间线和折叠栏目阅读长文，确认导师的按钮仍在方向选择附近。生活场景分段显示，加强文字对比度；手机使用原有入口和流式排版。

新增正文与英文对照在本地编写，并检查显示不会改变游戏状态或消耗随机数。日语、韩语新增长文采用有提示的英文回退，核心语言界面继续保留。所有文字随网页、离线HTML及桌面包一起提供，游戏过程中不调用外部翻译服务。


## v0.14.2：履历与游戏中的经过时间

普通生涯的任职日历使用公开履历中的既往经历，当前职级晋升后重新积累；稿件接收、学位结束与离组分开安排。年轻导师团队初始高年级同门参与合作团队的联合讨论，避免将其全部解释为导师刚入职后独立培养出的毕业生。旧有挑战节奏、已排定的答辩和等待中的晋升评议保留。

人物往事限于真正的导师交谈场合，合作标签本身不足以证明导师在场。人物档案只回看完成选择后已经记录的内容，并区分入组前履历与当前职级；查看不会写入新记忆或改变随机数。详见[检查记录](QA_v0.14.2.md)。

## v0.14.3 相处记录

人物对话引用当前存档保留的真实行动：一起练过的材料、请求是否接上、借用是否归还、作者顺序是否谈清。群体关系与个人缓存分开保存，求助按当下关系判断；早归还收回本次借用入口，但已完成核对不会被抹掉。没有过往记录时保持初识语气，不替旧存档编造求助结果。

普通生涯新增帮忙承诺的当事人及原始队列标记。同一个人可以有多个承诺，交接只更新对应的一条；推迟继续保留来源。与人的约定不作为科研补查任务，交接本身不提供科研核对记录。旧事件没有当事人标记时继续使用泛化后续，避免猜测身份；同局挑战保留此前的处理规则。

阅读入口沿用人物档案浅色布局，空记录、已离组成员、关闭后的焦点和窄屏换行都提供明确反馈。记录只展示存档目前保留的片段，受既有历史上限约束，不宣称保存完整人生。


## v0.14.4 学科语境与学习内容

方向库与故事共用同一份材料、疑点和边界。长线的核对卡只写待处理事项，不替资源失败的玩家编造拿到资料或已经发现结论。校园支线保留启动方向和课题版本，换方向以后可以回忆经过，不能从旧支线获得新课题的准备。组会追问保留原规则与实际准备门槛，回答后的解析讲清材料怎样支持判断。

真实机构只出现在明确标为现实参考资料的阅读区域。游戏导师、学校、期刊和会议仍然虚构，公开资料不被移植为人物成果。参考资料按其实际支持范围标注，共享主题、小练习和细分规则分别计数，不把生成的方向槽位当作同等数量的独立作者故事。

导师的岗位、职级与工作侧重分开；研究员序列的公开身份、教学安排和晋升段落对应其研究岗位。支持学生的性格影响失败反馈和已有心情损失，不改写证据完成情况，也不消除硬退出。界面仍然只把公开资料和少量线索放在初始介绍里，私人经历随剧情展开。
