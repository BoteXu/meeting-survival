# v0.14.0 验证记录

本轮重点修复无反馈的操作，并重写人物与连续事件。保持219条路线、4974位导师、766个结局及既有存档结构。

## 已定位并修复

- 自选交叉学科用通用占位方向筛选导师，候选数为零。改用两侧实际方向；随机推荐展示导师及申请方向，仍需明确确认入组。空搜索结果提供反馈，推荐遵守搜索及层级筛选。
- 周一预算事件尚未完成，准备／地点／课题安排可以写入状态，却仍显示预算事件。统一拦截与原因提示，并提供打开待处理事件的入口。
- 资源实查和修回等前置条件在部分界面只能静默拒绝。不可用选项禁用并说明条件，异常拒绝也有反馈。
- 全局快捷键可能穿透打开的弹窗；生活后果弹窗缺少Enter推进。现按当前弹窗处理，输入控件保留输入行为。
- 收起一个已展示故事后，再主动点击同一故事入口，事件编号相同导致弹窗没有重新打开。明确安排现在总会打开对应弹窗。
- 相邻转向和先看导师入口补齐相同检查；更换待导入备份会移除旧确认按钮。
- 手机导师列表限制局部高度，随机推荐在筛选区，长小传保持分段、深色文字和折叠栏目。

## 自动检查与真实浏览器

`tests/check-random-mentors.cjs`调用实际推荐／确认处理函数，覆盖3,200种专业领域及实际方向配置，逐一创建并验证生涯。它使用小型DOM替身；浏览器检查独立验证真实页面。

`tests/check-browser.cjs`使用独立测试来源和全新Edge Chromium上下文，走完14门类自然生活、组会、周末和周报告，轮换简化／中等／完整版与390px／1365px视口；验证随机推荐、手选方向、搜索空结果、层级、分页、新手引导、暂停继续、JSON下载与导入、17个主动行动入口及相邻转向。检查页面异常与横向溢出，实际截图随验证产生。

引擎回归包含24周投稿循环、252周世界事件循环、资源等待和实查、贡献署名、阶段与失败补救、旧存档升级、保存空间失败回滚及确定性重放。导师及故事检查验证履历年序、任职学校一致性、专业素材匹配、英文对照、稳定ID和阅读不消耗随机数。

28项引擎／结构／UI处理函数检查及离线打包检查通过；真实浏览器完成14门类的一周流程，共1,065次点击；新增阅读器另验390px和1365px、筛选、分页、百科／小说对应跳转、重载及离线零网络资源。断网检查四语言入口及下载HTML。69个根目录源码JavaScript文件通过语法检查。

`tests/check-offline-browser.cjs`打开最终离线HTML，完成随机推荐、入组、选择、推进和重载；四种语言网页分别等待PWA资源完整缓存，然后断网重载并继续学科选择。下载HTML不请求网络游戏资源。Windows包另核验可执行文件头、压缩包完整性和内含HTML与网页离线构建完全一致。

新增世界对应检查验证10所机构、78个唯一刊名、全部导师院系与创办年序；游戏手册的14个阅读入口在浏览器中检查，阅读前后游戏状态一致。

新增设定集检查复算正文汉字计数、百科／小说比例、人物身份对应、四幕结构、唯一章节ID、29册哈希和阅读器字节。2,188,145汉字仅指所编排的完整正文，包含复用段落；方法与去重统计写入清单，不当作完全独立手写字数。

## 范围与限制

检查使用隔离的测试存档，不修改已有玩家数据。没有穷举全部766种结局的浏览器路径，也不等于4974篇独立人工文学审稿。文字按专业素材及人物经历组合，仍有共享段落。医学等内容属于游戏编辑检查，没有逐方向外部专家签审。

390px浏览器验证覆盖手机排版；没有实体Android／iPhone安装验收。Windows启动器编译与包内容已检查；运行窗口依赖系统Edge／Chrome。新增长文提供人工编写的英文对照，日／韩仍有明确提示的英文回退。

## 重跑

常规检查：用Node运行`tests/check-*.cjs`，浏览器脚本除外。先用Python3运行`scripts/build.py`再检查`check-portable.cjs`。

浏览器检查需要已安装的Playwright；可用环境变量`PLAYWRIGHT_MODULE`指定模块，`BROWSER_CHANNEL=msedge`使用系统Edge。运行`check-browser.cjs`与`check-offline-browser.cjs`。结果与测试存档保存在忽略目录`.qa/`，不随发布上传。
