# v0.12.0 验证记录

2026-10-03。本记录区分自动检查、实际浏览器操作和未验证的平台。

## 内容与机制

24个 `tests/check-*.cjs` 脚本通过，包括旧规则与旧存档回归、准备与方向版本隔离、生活及组会、投稿、人物生涯、交叉课题、分类、导师、时间线、存档、离线构建和语言。

- 新的完整分类检查：14门类、165个非医科一级／专业／自由组合入口、667个非医科下层领域入口；总计219条路线、2484个研究方向、4974个导师档案。
- 2475个实际方向逐项检查导师：最低6位，均覆盖青年导师、副教授和教授。9个自由交叉占位方向不作为独立专业；实际交叉使用两侧具体方向与导师。
- 三种复杂度各覆盖218个实际单学科路线，共654个完整周、654场组会、8502次日常行动，状态与保存通过。该检查是自动模拟，不等于654次真人试玩。
- 生涯机制检查另覆盖219条路线各3周，共657周、8541次行动，检查资源、署名、阶段补救、校园支线与人物毕业。
- 新回归检查刻意保留错误的旧学科配置，再自动选择软件工程或神经病学，验证实际开局读取当前专业与方向。
- 未执行的课题安排可以转入资源前置预约，不计为完成，不增加依据，不重复预约等待中的资源。
- 暂停生涯可完整导出、交换恢复，保留累计结局；满8段仍可恢复。空间不足时保留原档，不产生嵌套暂停存档。
- 离线构建包含60个脚本、2234个组会场景、1095个准备事件、876个准备问题、766个结局，不需要外部游戏资源。
- 语言检查覆盖126738个故事字段；英文UI与内容提取未发现未翻译中文。新增专业段落在日文、韩文中部分回退英文，页面明确提示。

## 实际浏览器操作

- 工学 → 软件工程 → 测试与质量 → 软件测试 → 6位导师 → 明确确认入组。
- 日常选择 → 后果 → 时间推进 → 周五组会 → 结局 → 周末 → 报告 → 第2周；刷新后可继续。
- 医学 → 临床医学 → 神经病学 → 脑血管病 → 6位导师 → 完整版入组。
- 新专业开局后，在暂停列表恢复旧软件工程局，恢复到原第2周周一，累计结局保留。
- 导入专门复现前置阻塞的本地测试存档，被锁实查选项旁的资源入口能打开实际预约选项。
- 390px视口检查导师主页、中文／英文／日文／韩文界面，无整页横向溢出；手机日历在自身区域横向滚动，避免竖排碎字。
- 页面显示“离线资源已准备好”后，关闭专用预览服务器；重新加载，恢复同一存档，完成日常选择并推进到周一下半天。

## 验证范围

人物、学校、期刊和成果均为虚构。导师采用六种履历与培养框架，结合实际专业主题生成；多个专业共享资源与连续课题框架。内容完成编辑与机制检查，尚无逐专业外部专家签审。

Windows启动器已编译，打包时核对EXE格式及其离线页面内容。Android和iPhone提供PWA，尚未在两类实体手机上验收系统安装与长期保存；未提供APK或IPA。网页、下载应用与不同设备的存档各自独立，使用JSON导出／导入迁移。
