# 下一轮玩法设想

本轮已实现：临时交办、随机组员与经费、两个学科的联合问题、跨周校园支线、随机选项顺序和中英日韩版本。下面是尚未实现的扩展设计。

1. **同一局挑战朋友**：分享一个局号，朋友遇到同一批初始人物和事件，用不同选择走出不同结局。对比时展示完整路线，不能只比总分；语言不影响随机序列。适合跨国朋友各玩一局后讨论。
2. **人物记得具体的事**：一个同门记得你上次是否按约交付，而不是只记一个信任数。可以有修复关系、合作转交、邀请你加入新项目的事件；误解需要拿具体记录解释。
3. **研究生阶段变化**：新生、开题、资格考、写论文和答辩分别改变问题池与生活安排。可以延期、转方向、休整后回来，阶段转换由经历与材料触发。
4. **临时换位**：一周扮演导师或资深同门。有限经费要分给不同学生，临时任务交给谁、是否同意延期都会影响之后的组会；同一件事从不同角色看有不同成本。
5. **校园荒诞季**：校猫占据会议室、周年活动征用场地、共享盘文件命名大赛、食堂联名菜。荒诞事件也占用时间、有真实后续，并可通向专属滑稽结局。
6. **合作支线与竞争支线**：帮别人可能得到署名约定、反例或另一份记录，也可能被对方失约耽误。展示可核对的合作范围，贡献与关系各自记录。

优先顺序：同局分享 → 人物记事 → 阶段变化。前三项分别提高朋友之间的可比性、前后连贯性和长线变化；其余适合做可选玩法包。
