# v0.8可玩模式与边界

本版已经实现：消息来源与延迟后果、选择改变邀请池、限时机会、组会后回声、课题版本、人物目标与具体记忆、校园荒诞事件、七种模式、同局号挑战与本地路线对比。48条学科路线可以自选或盲盒混合。每条提供9个二级游戏方向，共432个；方向改变当前课题主题与版本追问，原学科的日常池继续使用。相邻转向按共同方法、对象或情境筛选，搜索可按方向、学科或连接点查找；转向耗时并重建版本，旧资料只留下参考线索。

同局挑战从独立生涯开始，固定初始配置。生活与组会使用可保存的种子；不同选择可能走向不同的事件，重载和换语言不会免费重抽。导出路线报告仅含经历与可见结果，报告格式为LM08-route；同局号、同一周的独立挑战才可对比。局号仅支持v0.8规则。

多语言卡片可本地保存，没有在线排行榜、实时多人房间、云存档或生成式模型聊天。角色、经历与研究问题均为虚构。

研究生阶段考核、导师/同门换位模式、实时合作对局是后续设计，本版不声称实现。
