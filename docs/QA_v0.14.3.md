# v0.14.3 相处、承诺与资源交接

本次继续修正具体衔接，保留219条路线、2484个方向、4974位导师及766个结局。没有通过重复添加事件来增加数量。

## 复现与修正

- 借用逾期的惩罚会先更新课题组成员的关系值，个人生涯对象的缓存直到行动后才同步。求助原先读取缓存，可能忽略刚发生的关系变化；普通生涯改为读取当下成员关系。正常带教完成后的同步原来存在，不将其列为旧版缺陷。
- 提前归还借用原先只关闭借用记录，没有关闭同一次借来的资源窗口。现在会归档并交回对应窗口，后续使用需要重约。归还其他借用不影响当前预约；归还不删除已完成的核对。
- 帮忙原先必然换来一周延期，即使对方即将答辩。现在先投入时间，再按对方的使用安排、关系与回应判断；不能延长时，帮助已发生，原归还期限保持有效。低年级同门的选项不再统一写成准备答辩。
- 合作进行到自己的工作完成时，原文已经声称伙伴提供了记录，实际交接却还未发生。改为描述待交接状态。已有署名争议时也不再写成署名已确认。
- 普通生涯的人物帮忙承诺保存当事人和原始事件。推迟会再次由同一人询问；处理只更新相应承诺，同一人可以有多个约定。科研补查不再自动消掉帮忙承诺。处理了一部分、重新商量范围与全部完成分别表述。
- 实际相处后保存时段及已知结果。求助没有接上、交接办法没有被接受，都按相应结果描述；没有结果字段的旧记录不被推断成成功。

## 页面与叙述

- 课题组成员卡和离组同门的年鉴增加“相处记录”，展示实际带教、求助、交办、借用与合作的片段。后续人物交谈引用相应经历，避免只有“对方记得你”的泛化提示。
- 相处记录只读取已有存档，不奖励关系、不完成研究、不消耗随机数。空记录有说明，关闭后焦点回到入口。沿用浅色人物档案布局，手机宽度可完整阅读。
- 过去的口头答应按当时状态描述，不把已经有后续的旧片段继续标成当前待完成。旧事件没有当事人时保留泛化后续，不猜测是哪一个人。
- 本局中的往事和互动记录仍采用既有上限，入口明确只展示保留片段，不宣称是完整人生档案。结局收藏和完整JSON导出沿用已有保存机制。

## 验证

31组非浏览器检查和71个根目录JavaScript语法检查通过。学科流程模拟覆盖219条路线的657个模型周；这是机制模拟，不是657周自然浏览器试玩。新增测试直接复现过期关系缓存、错误预约保留、答辩前延期、材料尚未交接、同一人物多个承诺与旧记录缺字段等情况。

与v0.14.2发布源码保存的相处处理样本比较，挑战状态摘要一致；已有职业样本继续比较30周随机数、晋升和同门对象。本版普通生涯启用新的延期与承诺规则，同局挑战沿用旧处理。比较只覆盖所留样本，不能声称穷举所有挑战码。

新入口在390px与1365px、简化版与完整版的独立浏览器上下文中测试。完整版通过真实按钮完成带教、推进、回看、刷新恢复；用受控离组状态测试年鉴入口。空记录、重复打开、Escape关闭、焦点恢复、英文标题、页面溢出及正文/标题/按钮/脚注至少4.5:1对比度检查通过。

真实浏览器检查覆盖14个学科门类，每个完成一周，包含随机选择导师、阶段结算与继续，共1067次点击且无页面异常。还检查搜索、层级筛选、翻页、手选方向、暂停、完整JSON导入及主要行动入口；用独立测试来源和新浏览器上下文，没有打开玩家已有档案。

构建后的中文离线HTML通过选导师、行动、推进和刷新恢复，HTTP请求数为0。中文、英文、日文、韩文四个PWA入口完成缓存后断网刷新，学科选择和世界设定集都能继续使用，无页面异常。四个入口测试不表示所有长篇叙述都完成了四语言独立人工润色；原有翻译范围与回退策略继续保留。

Windows包完整性、七个附件的摘要及部署文件与发布提交的对应关系，作为发布验收另行执行。

## 范围

本次是故事连续性与软件行为检查，没有重新逐条专家审阅专业问题，也没有新增独立手写人物小说。世界设定仍为2,261,146汉字，百科1,191,494、小说1,069,652，包含已披露的共享段落。

手机以可安装PWA兼顾Android和iPhone；浏览器窄屏与离线检查不等同于两种手机真机测试。Windows包使用本机已有Edge/Chrome，继续保留本机数据及导出方式。
