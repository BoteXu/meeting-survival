# v0.14.1 人物一致性与操作细节检查

本轮收敛导师选择页，修正履历和小说中的时间、署名与投稿衔接，补上逐步听到人物往事的机制。保留219条路线、2484个方向、4974位导师、766个结局及既有身份ID。

## 修订内容

- 招生主页只展示公开履历、代表工作、方向、培养与资源安排。完整小传保留在内容资料中；学生往事、转折、生活和私人痕迹不在入组前全部展示。
- 导师往事在真正发生的导师拜访、本人委托或合作推进中分段出现，参考已完成的拜访、相处周数与当前信任。仅打开页面不会记录完成；回应当前事件后，听过的段落写入生涯存档，同一导师同一段不重复发放。此机制不增加科研回执、奖励或随机抽取。
- 年轻导师的首批独立指导学生仍在读。求学阶段、原团队的资料、协助交接与自己的独立带组区分；小说中的高年级同学说明来自联合讨论的合作团队。
- 代表工作的期刊与论文类型逐项按对应方向匹配。加入现校前的合作稿标明原团队，避免把过去合作第一作者写成现校本组学生。
- 小说的返修先交代投稿与送审；接收前补修回与等待。暂停或改题若发生于在修稿件，说明撤回。教学案例对应实际发生的来源误会，不随机附到任意成功报告后；继续深造邀请不在同篇结尾重复发出。
- 随机校园支线让位于已经明确安排的拜访等地点行动，保留支线后续，避免入口显示成另一件事。
- 导师方向切换、搜索与筛选保留当前人物的折叠阅读状态。推荐定位到被选导师所在页；搜索包含实际方向名称与题目。当前主页不符合筛选时明示状态。
- 阅读器全文搜索、空结果正文、异常章节链接、浏览器返回、对应百科／小说跳转、分开的目录翻页与章节翻页、字号上下限、阅读进度和恢复上次位置均有处理。阅读进度使用独立键，不改游戏存档；存储失败保留阅读功能。手册关闭重开保留当前章节。

## 验证方式

本版通过29项引擎／结构回归和69个根目录JavaScript语法检查；3,200种随机导师配置、4,974位履历、14,911项代表工作与405篇小说关系检查通过。真实浏览器跨14门类完成一周及主动入口、暂停与存档导入，共1,048次点击，未记录页面异常。另通过390px／1365px细节回归、独立阅读器离线检查和最终四语言PWA断网重载。Windows启动器重新编译，包内游戏与阅读器逐字节对应最终离线构建。

`check-fine-details.cjs`检查全部导师年代和逐项期刊、年轻导师阶段限制、405篇小说人物和投稿关系，并用实际生活事件验证新往事的展示、选择、记录、待处理状态与JSON重载。`check-narrative.cjs`保留稳定ID／玩法参数、英文字段和阅读不消耗随机数的检查。

`check-detail-browser.cjs`在隔离Edge上下文中检查390px和1365px页面，复现异常链接、全文靠后词语、空分类重载、阅读进度、字号、历史返回、对应跳转、存储失败、导师折叠／推荐／题目搜索、手册重复打开和记忆章节。后续周的往事触发使用明确控制的测试状态，并通过实际按钮选择、保存、重载、继续推进；不声称自然玩完六周。

常规回归另检查随机导师与入组、旧存档、资源与投稿、阶段目标、生活后果和确定性。完整一周的跨14门类流程、离线HTML、四语言PWA断网重载与Windows包内容分别验收。截图为真实浏览器输出，公开验证不包含玩家原存档。

## 内容与平台范围

正文计数、比例与各册哈希以[当前清单](worldbook/manifest.json)为准。共享场景与人物编排仍有复用；405篇学年小说是阅读分支，不是同等数量的新玩法。当前小说结果包含在审、拒稿、暂停、接收、改题和未定去向。完整设定阅读器保留作者资料，游戏中的人物往事逐步出现。

这些检查不等于逐位人工文学审稿、外部学科专家签审或穷举所有结局。手机按浏览器视口与PWA缓存检查，没有实体Android／iPhone安装验收。Windows核验编译与包内文件；系统浏览器运行仍依赖用户环境。新增游戏段落提供英文对照，日／韩沿用明确提示的英文回退，世界设定集为中文。
