# 方向内容库与作答解析 · v0.14.4

游戏的2,484个方向各有稳定ID的内容库：材料、核对思路、典型疑点、解释边界、五类问题及三段长线核对提示。问题围绕读文献、设计、原始记录、结论范围和解释展开；方向转向后，依据仍按方向与课题版本分别判断。

这些库由103个编写的主题模块结合方向名称与课题组成，共12,420个问题槽位。相近方向会共享研究方法、案例与句式。这不等于逐条独立写成12,420道专家审定题，也不等于2,484条独立小说。[方向与模块对应表](DIRECTION_BANKS.csv)公开匹配方式，便于逐方向继续编辑。

例如心力衰竭讨论功能分型与再住院随访窗口，心律方向讨论监测时长与未捕获事件，数据库讨论运行与一致性条件，护理讨论交班记录与患者体验，文学讨论版本和叙述层次。内容是学术判断的练习；医学生物方向只讨论资料、设计和解释，没有临床处方或实验操作步骤。

日常准备与组会问题共用当前方向的材料提示。长线的三个阶段展示对应核对卡，卡片使用待核对语气；实际是否拿到材料、核对成功或缩小范围，仍由原事件的行动结果决定。校园支线记录保存启动时的方向及课题版本，旧经历不能给新方向提供完整准备。

作答后可以展开解析，结束组会后保留最近80条学习札记，跨周、存档与备份继续保存。阅读内容库或札记不增加任何准备值，不消耗随机数。没有实际做过的准备仍不能使用完整依据回答。

导师岗位分为教师序列与研究员序列，职级仍用原来的青年、中坚、资深ID保存；岗位侧重另分教学型、科研型、教学科研型。普通方向至少六位可申请导师包含两种序列与三种侧重。交叉方向按玩家选定的两侧学科匹配导师，不把通用交叉主题当成独立招生资格。研究岗位的小传、教学任务、加入现校经历、职级晋升文字与岗位保持一致。岗位侧重体现在简介、安排和晋升说明；本版没有另建三套晋升分数算法。

导师的带教耐心和研究要求分开表示。支持型导师遇到诚实承认缺口或有实际准备的失败回答，会提供补救反馈，最多减轻两点已有心情损失，至少保留一点损失。证据、耐心、危机、随机负面事件与退出条件仍按原规则判定；支持不会创造准备、抹掉缺口或替整活兜底。

## 方向资料与进一步细化

每个方向增加三步阅读思路、一个有三种处理方式及对应解析的小练习，并列出实际参考入口和使用范围。共29个公开的一手资料入口，按主题共享映射到2,484个方向；不是2,484份各自独立的参考书单。另有43条细分核对规则，本次匹配281个方向，改变这些方向的材料、核对、典型疑点与解释边界，并同步用于日常准备、专业追问、长线提示与作答解析。

[方向内容与资料对应表](DIRECTION_STUDY.csv)列出每一项方向的焦点、材料、核对、疑点、解释边界、链接与链接范围。分类、相邻学科介绍、基础课程与具体方法资料分别标注；只支持学科范围的页面不被写成该方向每道题的直接依据。小练习是游戏编写的证据判断案例，三种反馈均可阅读，不产生准备、成绩或存档变更。

修正基于关键词造成的错配：分析化学、高分子、原子与分子物理、统计物理、太阳与空间环境、人文地理、古代史等，先按宿主学科区分含义。人文地理以区域尺度和人口活动为材料；自然地理以环境观测和覆盖范围为材料；历史文献以版本和形成时间为材料；科技考古保留层位与来源语境。

新增参考入口包括[北京大学城市与经济地理系](https://www.ues.pku.edu.cn/Geography/)、[自然地理与自然资源系](https://www.ues.pku.edu.cn/ztlm/zrdlyzrzyx/index.htm)、[MIT实分析课程](https://www.ocw.mit.edu/courses/18-100c-real-analysis-fall-2012/)、[力学与材料课程](https://ocw.mit.edu/courses/2-001-mechanics-materials-i-fall-2006/pages/syllabus/)、[NINR护理研究优先领域](https://www.ninr.nih.gov/research/priority-areas)、[FDA药物开发背景](https://www.fda.gov/patients/learn-about-drug-and-device-approvals/drug-development-process)。这些真实机构只出现在明确的参考资料区域，不成为虚构角色的履历或游戏学校。

当前已补齐方向库的结构与参考映射，但每个细分方向仍不等于一部完整课程或专家审定题库。281项细化之外的方向继续采用带自身主题的共享方法模块；专业内部更细的理论问题、地方制度与真实频率尚需继续逐项校订。
