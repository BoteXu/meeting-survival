# 研究室ミーティング・サバイバー

架空の大学院生活を体験する選択式ゲームです。月曜から木曜に準備し、金曜の研究室ミーティングで報告。週末はフィードバックへの対応や休息に使います。

すべての行動は限られた同じ時間枠を使います。文献、手伝い、食事、休息は同時にできません。依頼を引き受けても完成ではなく、実際に作業する時間が必要です。

十分な回答には、その分野で確認した記録が必要です。要旨から得られるのは手がかりだけ。カード、高い数値、別分野の準備では代用できません。

指導教員、先輩、後輩の人数はランダムです。研究費の余裕は週をまたいで変動し、依頼、締切、相手の関心、返答の結果が予定を変えることがあります。

学際モードでは二つの分野を選びます。それぞれの問いに加え、定義・前提・利用場面のつながりも確認します。両側の根拠を別々に準備してください。

通常は少なくとも10回回答してから終了できます。ただしメンタル、忍耐、時間が尽きると早く失敗します。失敗後も生活は続きます。保存はこのブラウザー内で行われ、言語を変えても進度は維持されます。

155ルート、1716の研究方向があります。拡張ルートは各12方向、既存ルートは各9方向です。隣接方向は方法・対象・利用場面のつながりで選ばれ、検索できます。転向を確定すると時間枠を使い、新しい課題版を作ります。以前の資料は手がかりとして残り、十分な回答には新しい確認が必要です。

情報が正しいとは限らず、確認してもすぐ返事が来ない場合があります。機会を予約しただけでは参加したことになりません。登場人物には自分の予定があり、選択が後の誘いを変え、ミーティング後の返事から新しい依頼が来ることもあります。

7つのモードで大学生活の展開が変わります。同じシードのチャレンジは独立した経歴から始まります。局コードと同じ週の報告を共有し、友人は自分の言語でプレイできます。報告を貼り付けて分岐を比較します。リアルタイムのオンライン対戦ではありません。

修士・博士・自由な研究生活と6種類の開始条件を選べます。他の学生にも投稿、発表、就職の予定があります。資源は予約して待ち、実際に確認して記録を残します。共同研究では貢献と著者順を合意します。失敗の後にも立て直しや週をまたぐ物語があります。保存とインストールから完全なJSONバックアップを作れます。AndroidとiPhoneはオフラインWebアプリ、Windowsはダウンロード版に対応します。

14の大分類から専門を選びます。一部の専門では細分領域を選べます。先に教員ページへ進み、1〜3の方向から選ぶこともできます。今回追加した専門テキストの一部は英語で表示されます。

指導教員のページには1〜3の研究方向と職位が表示されます。その方向を選ぶか、元の課題で協力できます。教員の昇進は週をまたいで申請と審査が進み、通過や延期があります。分野別の物語は実際の時間枠を3回使い、最後の提出は翌週以降です。課題で3件の確認記録と限定的な結論を用意すると投稿できます。修正にはその原稿の作業記録が必要で、再提出後も審査を待ちます。原稿は独立した版を保存し、新しい課題は草稿から始まります。採択された成果と関係によって博士課程への誘いがあり、承諾・保留・辞退を選べます。

英語・日本語・韓国語の物語は機械翻訳を使用し、主要用語とサンプル画面を確認しています。翻訳データは同梱され、プレイ中の通信やAPIキーは不要です。
