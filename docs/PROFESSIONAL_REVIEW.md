# 逐专业内容审核 · v0.12.0

审核范围：219条路线、2500个专业研究分支、专业提问、生活准备、学科突发、资源类型、方向联系和结局。由Codex进行编辑与机制审核，没有外部专家逐条签审；文本测试通过不等于学科事实得到专家验证。

主要修正：医学问题的拼接式措辞、参数区间与个体预测范围的混说、研究分支上下文缺失、旧方向准备能回答新方向问题、医科分支一律使用空泛“资料与解释边界”等。新增分支焦点与问题示例。方向转向依靠路线联系和共享标签；旧材料降为参考，新方向与新版本需要自己的准备。

[2500项方向审核表](DIRECTION_REVIEW.csv)逐项记录ID、名称、焦点、问题示例、连接标签、相邻数、内容与机制检查以及重叠说明。跨路线有相同研究主题可以合理保留，不能把名称重叠当成同一专业或自动迁移成果。

名称分类依据教育部研究生教育学科专业目录及临床医学学位授权审核要求；游戏路线还包含专科、交叉主题与资料方法，不逐项等同官方一级/二级学科。

来源：[研究生教育学科专业目录2022](https://www.moe.gov.cn/srcsite/A22/moe_833/202209/t20220914_660828.html)；[2024临床医学授权审核条件](https://www.moe.gov.cn/srcsite/A22/yjss_xwgl/moe_818/202405/W020240520385029435154.pdf)。这些来源支持命名层级，不支持游戏里虚构的人物、随机事件和结局。

仍需专业试玩：具体导师的真实说话习惯、专业内部的细致分工、日常频率与地区差异。医学问题描述研究资料和解释，不提供诊疗或实验操作。

## 🧪 生物 · 基础医学

- 审核语境：生物现象、材料批次与观察记录。
- 核心边界：同一对象内的重复观察不能自动代表多个独立对象。
- 专业提问：这些观察来自哪些独立对象，批次与组别是否重叠？
- 审核分支（9项）：分子与细胞、生理与病理、组学与系统生物学、发育生物学、神经科学、免疫研究、遗传学、微生物与宿主、生物信息学。
- 资源安排：bench；题目与当前方向、准备来源及版本关联。

- 专业提问：训练、选择和最终评估的材料有没有发生交叉？
- 审核分支（9项）：机器学习、软件与系统、人机交互、计算机视觉、自然语言处理、数据库与数据工程、计算机安全、分布式计算、因果与可信人工智能。
- 资源安排：compute；题目与当前方向、准备来源及版本关联。
