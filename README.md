# 组会求生 · Lab Meeting Survivor

**同学，你能活着散会吗？**

一个原创中文文字选择小游戏。选学科、选人设，面对导师、统计老师、师兄和恰好路过的大佬。老师说“最后一个问题”时，组会往往才刚开始。

纯娱乐，角色、事件和结果均为虚构。

**[在线玩](https://botexu.github.io/meeting-survival/) · [下载离线版](https://github.com/BoteXu/meeting-survival/releases/latest) · [详细玩法](怎么玩.md)**

## 十门学科，十种组会人生

| 学科 | 今天的问题 |
| --- | --- |
| 生物 · 基础医学 | 仪器有脾气，实验室有猫。 |
| 临床医学 | 课题在手，排班在后。 |
| 计算机 · AI | 程序能跑，研究者想跑。 |
| 数学 | 证明有边界，组会没有。 |
| 物理 | 宇宙很大，误差条很长。 |
| 化学 · 材料 | 谱图很密，瓶签很小。 |
| 经济 · 管理 | 假设很强，预算很弱。 |
| 社会 · 人类学 | 你在田野，组会在找你。 |
| 文学 · 历史 | 正文八页，脚注十八页。 |
| 艺术 · 设计 | 甲方说好，但再改一下。 |

每门学科有七个专属事件和隐藏结局，穿插公共组会剧情。新开局会尽早遇到所选学科的故事。

## 能玩到什么

- **120个组会事件 + 8个场外事件，384条回应，22种结局。**
- 四种人设：初来乍到、熬夜卷王、淡定摸鱼人、学术社交王。
- 四种导师风格：捧场型、细节控、往事型、冷面型，可指定或每场随机。
- 三档难度：正常组会、周五晚八点、大佬突袭。
- 心态、底气、导师耐心、模拟剩余时间，以及会延续到下一场的师门关系。
- 专属技能、救场道具、摸鱼币补给站、剧情记忆与散会后的生活。
- 自动保存、继续上一场、结局图鉴、结局卡、复制战绩和可关闭的音效。
- 电脑和手机布局，键盘1/2/3选择回应，Enter继续。

没有固定十回合限制，也没有真实倒计时。你可以慢慢想；也可以在讲过五个回合后尝试申请散会。

## 直接开玩

### 在线版

打开 **https://botexu.github.io/meeting-survival/**。不需要注册、模型密钥或安装依赖。

### 离线版

在 [Releases](https://github.com/BoteXu/meeting-survival/releases/latest) 下载 `meeting-survival-offline.html`，用浏览器打开即可。所有界面和剧情都包含在这个文件里，可以离线玩，也可以发给朋友。

仓库中的 `组会求生_直接玩.html` 是相同内容的中文文件名版本。下载源代码或试玩包后，直接打开它也可以。

### 本机预览

直接打开 `index.html`，或在安装Node.js的电脑上运行：

```sh
node server.cjs
```

然后访问 http://127.0.0.1:8768/ 。预览服务仅监听本机。

## 存档

游戏使用浏览器本地存储。不会上传存档或调用模型服务。清除浏览器数据、换浏览器或换访问地址，会使用另一份存档；在线版和离线版不会自动同步进度。

同一入口的v0.1存档可以继续使用，原组会迁移为生物与基础医学、捧场型导师。结局卡可下载，浏览器限制下载时也可以保存预览图片。

## 源码与检查

原生HTML、CSS和JavaScript，无运行时第三方依赖。

```sh
# 检查剧情规则、存档迁移与结局路径
node tests/check-engine.cjs

# 重新生成离线单文件与试玩包，需Python 3
python scripts/build.py

# 检查离线单文件的脚本和内容
node tests/check-portable.cjs
```

v0.2规则检查覆盖8,880场模拟、十门学科的剧情隔离、全部120个组会事件，以及22种结局的实际路径。另做了浏览器试玩，检查旧存档恢复、道具库存、场外奖励和手机布局。
